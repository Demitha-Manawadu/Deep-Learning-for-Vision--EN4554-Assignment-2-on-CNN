# Export the final report

Use `220381M_a02.ipynb`. It already includes results; do not rerun training to export it.

## HTML then PDF (no LaTeX needed)

In a terminal in this project folder:

```powershell
python -m pip install nbconvert
jupyter nbconvert --to html --embed-images 220381M_a02.ipynb
```

Open the generated `220381M_a02.html` in Chrome or Edge. Press Ctrl+P, choose Save as PDF, turn off browser headers and footers, and save as `220381M_a02.pdf`. Enable background graphics if needed for chart/table formatting. Check the print preview and adjust scale or orientation if wide content is clipped.

Before uploading, check the PDF includes the bordered title, name and index, important code, every plot and table, the extra Task 3(a) gap image, interpretations, discussion points, conclusion, GitHub link, and AI acknowledgment. Confirm the final test accuracy is 88.51% and no code/table columns are cut off.

Only the PDF is the requested submission; keep the notebook as the editable source. The PDF has not been generated by this editing step.
